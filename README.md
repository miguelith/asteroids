# Asteroids

A simple Asteroids-style arcade game built with Python and Pygame as part of the [Boot.dev](https://www.boot.dev/) curriculum.

## Features

- Player movement and rotation
- Shooting with a cooldown
- Randomly spawning asteroids
- Asteroids splitting into smaller pieces when shot
- Collision detection and game-over handling

## Controls

| Key | Action |
|---|---|
| W / S | Move forward / backward |
| A / D | Rotate |
| Space | Shoot |

## Running the Game

Requires Python 3.13+ and [uv](https://docs.astral.sh/uv/).

```bash
git clone https://github.com/miguelith/asteroids.git
cd asteroids
uv sync
uv run main.py
```
